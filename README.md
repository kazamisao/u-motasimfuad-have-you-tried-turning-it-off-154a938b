# Have You Tried Turning It Off?

One line from a support agent who cannot honestly promise that a customer's wedding photos survived — so he sells the only upgrade he is authorised to give: he will keep saying "when we find them" instead of "if", and that optimism is free on the customer's plan. The recovery is doubtful; the hope is unlimited, guaranteed, and billed at zero.

The program is a single standard-library file. It holds the line, checks it against the 1–199 character window, and writes it to the output directory exactly the same way on every run.

## Run

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
